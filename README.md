# 🚇 Buscador Metro de Santiago

Proyecto desarrollado en Python para encontrar rutas entre estaciones del Metro de Santiago, minimizando la cantidad de combinaciones o transbordos.

## Descripción

El sistema representa la red actual del Metro de Santiago mediante un grafo de estaciones y las seis líneas que componen la red.

Permite al usuario seleccionar una estación de origen y una estación de destino, entregando la ruta recomendada con la menor cantidad posible de combinaciones o transbordos.

Este proyecto aplica conceptos de:

- Sistemas Inteligentes
- Búsqueda en grafos
- Representación del conocimiento
- Sistemas basados en reglas

## Requisitos

- Python 3.8 o superior

## Ejecución

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
